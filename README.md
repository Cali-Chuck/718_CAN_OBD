This repo leverages GitHub's ability to serve simple, static, public web sites to host a consolidated master list of back-
engineered CAN, OBD Basic (Mode $01) and OBD Extended (Mode $22) telemetry signals for Porsche 718 platforms. These have been contributed by a working group of a half-dozen collaborators with various 718 models.

This telemetry enables 718 Boxster & Cayman owners who use mobile lap timers such as RaceChrono, Harry's Lap Timer, Track
Attack or others that support external Bluetooth OBD/CAN dongles like OBDLink MX+ to capture realtime telemetry for use on
track and at home to produce videos and perform deep-dive analysis in platforms such as VBox Circuit Tools. Owners of 
hardwired in-car telemetry systems from VBox, Aim, RaceNavigator and others can also profit from this list.

THE REPO IS NOT INTENDED TO BE PUBLICLY MODIFIABLE AT THIS TIME.

PLEASE DIRECT ADDITIONS OR PROPOSED CORRECTIONS TO @CALI_CHUCK ON 718FORUM.COM.

As of the last update (2026-09-28) the site consists of these pages:

  -  Master signals list - customizable in realtime via DHTML for each user
  -  Telemetry tutorial including how to get started with CAN bus
  -  DBC file containing definitions for all of the CAN signals on the master list
